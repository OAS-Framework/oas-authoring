# Lessons

* [Never use bare `node --test` in an OAS repository](bare-node-test-discovery-in-oas-repos.md) - Unbounded test discovery recurses into agents/<soul>/instances/<id>/work trees and runs stale sibling suites, making the package gate's result depend on which agents happen to be alive.
* [Lexical path prefix checks are not containment checks](lexical-path-checks-are-not-containment-checks.md) - A rule enforced on the spelled path — string prefixes, hand-written path regexes — is bypassed by symlinks and by ordinary quoting; resolve first, then compare.
* [agent-types targeting must be a YAML mapping — a block list silently activates nothing](oas-config-agent-types-must-be-a-mapping.md) - The OAS config parser has no block-sequence support, so `agent-types:` written as a `- name` list parses to an empty mapping and the capability activates for nobody, with no error anywhere.
* [oas okf harvest cannot spawn from an attached-mode instance](oas-okf-harvest-fails-from-attached-instances.md) - Attached agents are forced to be children of the work-tree owner, which conflicts with the relation flags the OKF harvest helper passes, so notes never reach the soul from a guest instance.
* [A one-shot reviewer that retires before mailing loses its verdict with no trace](one-shot-reviewers-can-lose-verdicts-silently.md) - Retirement deletes the instance home, so a reviewer that dies before delivering leaves no verdict, no transcript and no error — the only signal is the roster going quiet.
* [Probe OAS packages against the released CLI pinned as a devDependency](probe-released-oas-cli-as-a-pinned-devdependency.md) - Consumer probes must drive the exact released OAS CLI they claim compatibility with and assert end effects in throwaway scopes.
* [Never interpolate a temp path into a shell command — TMPDIR is attacker-controlled input](shell-interpolation-of-tmpdir-in-tests.md) - JSON.stringify quoting does not stop command substitution inside sh -c, so a directory name containing $(...) executes arbitrary commands during an ordinary test run.
* [Never verify an escaping-sensitive finding through an inline shell command](verify-escaping-sensitive-findings-from-a-file.md) - Checking a backslash-handling bug with node -e inside a shell returned a false "caught" — the shell mangled the test string before the code ever saw it.
